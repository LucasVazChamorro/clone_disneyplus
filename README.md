# 🎬 DISNEY+ CLONE — Landing Page Interativa com SASS e JavaScript

📌 **Deploy online:**  
👉 [Acesse aqui o site publicado via Vercel](https://clone-disneyplus-wine-one.vercel.app/) 

Este projeto foi desenvolvido como parte do meu aprendizado contínuo em desenvolvimento web. Trata-se de um **clone da landing page oficial do Disney+**, com design responsivo, interação dinâmica com abas e perguntas frequentes, uso de **SASS modularizado** e automações com **Gulp**.

> O principal objetivo foi aplicar de forma prática os conhecimentos em **HTML5, SASS, JavaScript puro** e ferramentas de build modernas — simulando uma estrutura profissional de front-end.

---

## 📁 Arquivos do Projeto

- `index.html`: Estrutura completa da página com HTML semântico  
- `main.scss`: Arquivo principal que importa todos os estilos SASS  
- `_*.scss`: Módulos SASS para cada seção do site (header, hero, footer, etc.)  
- `main.js`: JavaScript puro para controle de abas, scroll dinâmico e FAQ accordion  
- `gulpfile.js`: Arquivo de automações com Gulp (SASS, JS e imagens)  
- `package.json`: Dependências e scripts para build e desenvolvimento  
- `dist/`: Pasta com arquivos finais otimizados (CSS, JS, imagens)

---

## 🌐 O que foi feito com **HTML**

✅ Estrutura semântica com `<header>`, `<section>`, `<footer>`  
✅ Divisão clara por áreas: combos, planos, dispositivos, perguntas frequentes  
✅ Navegação com tabs e botões interativos  
✅ Responsividade garantida com meta viewport e uso de boas práticas

---

## 🎨 O que foi feito com **SASS (CSS)**

✅ Modularização completa com arquivos `_header.scss`, `_hero.scss`, etc.  
✅ Variáveis globais para cores, tamanhos e espaçamentos  
✅ Aninhamento de seletores e organização lógica com `@import`  
✅ Estilo responsivo com media queries  
✅ Visual fiel ao layout oficial da Disney+, com botões e seções bem definidos

---

## 🧠 O que foi feito com **JavaScript**

✅ Lógica de tabs interativas usando `data-*` e manipulação de DOM  
✅ Efeito de esconder/exibir o cabeçalho com base no scroll  
✅ Sistema de FAQ com efeito de abrir/fechar respostas (accordion)  
✅ Código limpo, modular e com boas práticas de escrita

---

## ⚙️ O que foi feito com **Gulp**

✅ Compilação e minificação de arquivos SCSS com `gulp-sass`  
✅ Otimização de imagens com `gulp-imagemin`  
✅ Minificação de JavaScript com `gulp-uglify`  
✅ Automatização de tarefas com o comando `npm run build`  
✅ Observador de arquivos para desenvolvimento com `npm run dev`
